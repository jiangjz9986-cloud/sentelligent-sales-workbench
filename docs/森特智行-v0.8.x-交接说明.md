## 新设备恢复步骤

1. 安装 Git、Node.js 24、npm 和 Chrome（浏览器集成验收必需）。
2. **从旧设备完整迁移本机仓库**（GitHub 不含 v0.6.2 之后的历史）：迁移 `repos/sentelligent-sales-workbench` 整个目录（含 `.git`），或 `git bundle create` 全量 bundle 后在新机 `git clone <bundle>`；核对 `git log --oneline -1` 与 tag 链完整性（`git tag -l 'v0.*' | wc -l`）。
3. 安装依赖：`npm ci --prefix backend && npm ci --prefix outputs/product-design-prototype`。
4. 通过可信带外渠道转移本机私密配置与 SSH 私钥（`ssh.pem`）；检查 ACL 与 SHA-256。
5. 按 `.env.example` 创建本机配置，变量名清单（值只在私密环境保存）：
   - `AUTH_ACCOUNT`、`AUTH_PASSWORD_HASH`、`AUTH_SESSION_SECRET`
   - `MODEL_PROVIDER`、`MODEL_API_KEY`、`MODEL_BASE_URL`、`MODEL_NAME`、`MODEL_TIMEOUT_MS`
   - `AMAP_WEB_SERVICE_KEY`、`VITE_AMAP_WEB_JS_KEY`、`VITE_AMAP_SECURITY_CODE`
   - `WEIXIN_AGENT_API_TOKEN`、`ASSISTANT_CONFIRMATION_SECRET`、`WEIXIN_AGENT_BACKEND_URL`、`WEIXIN_AGENT_OWNER`、`WEIXIN_ALLOWED_SENDER_IDS`
   - `INVOICE_OCR_COMMAND`、`INVOICE_PDF_TEXT_COMMAND`、`INVOICE_OCR_LANGUAGES`
   - （`ICOST_WEBHOOK_*` 已随快捷指令 Token 退役，无需配置）
6. 跑全量门禁验证环境：backend `npm test` → `qa:local`（**必须显式传 `CHROME_PATH`**）→ `qa:integration` → `qa:webkit` → 根 `test:deploy`。
7. 继续生产开发前先读：最近版本 `docs/releases/vX.Y.Z.md`（完整 runbook 与踩坑）、`docs/部署记录.md`（运维注意事项）、`docs/正式交付验收手册.md`。生产证据有时效，必须重新采集。

## 部署 runbook 要点（血泪坑全集）

1. **串行门**：上一版 tag 在位、工作树干净、current 与其 postflight/冒烟证据在位后才开工。
2. **bundle 路径**：本地 `git bundle` → scp → 服务器 SHA-256 复算一致（600 权限）。
3. **服务器打包必须 `LC_ALL=C`**：git 1.8 中文 locale 报错文案会绕过脚本英文正则（v0.7.4 坑）。
4. **preflight 对切换前 current** 跑 25/25（expected-commit 填 current 的 commit），**postflight 对新 release** 跑 25/25。
5. **冒烟密码经 JSON stdin 传递**，只 grep 提取 `DATABASE_URL`/`AUTH_SESSION_SECRET`，全程不 source 不落日志；临时凭据经 `/dev/shm` 内存备份做**字节级恢复**（bytes-identical 断言）；`quick-record.preview` 偶发瞬态失败允许重跑一次（历史多次出现）。
6. **release 目录权限归一**：root:root、目录 755/文件 644 显式 `find` 归一并抽查。
7. **迁移幂等**："Database migrated" 是幂等 runner 常规输出，`schema_migrations` 计数不变即为零迁移。
8. **受保护边界**：只动三个项目服务；共享 Caddy/轻氧勿碰；`.production-cutover.lock` 残留是正常现象。
9. **回滚**：只把三个 systemd 单元重新固定到上一 release 目录；不重启 Caddy、不直接恢复数据库。
10. **证据回填**：部署完成后把证据表写入 `docs/releases/vX.Y.Z.md` 并追加提交（tag 不动）。
