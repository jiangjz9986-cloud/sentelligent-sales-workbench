# 需求与验收矩阵

状态定义：

- `已验证`：实现和自动化/实际流程已有证据
- `已实现`：代码存在，仍需当前版本完整回归
- `开发中`：正在实现或整合
- `待开发`：尚未形成完整闭环
- `暂缓`：产品决定当前版本不建设写入能力
