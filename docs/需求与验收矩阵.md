# 需求与验收矩阵

证据更新时间：`2026-08-28`（v0.8.4 工程健康回填；生产基线 v0.8.3，逐版证据见 `docs/releases/`）

状态定义（四态口径沿用）：

- `已验证`：实现和自动化/实际流程已有证据（引用的 release/测试为准）
- `已实现`：代码存在，仍需当前版本完整回归
- `暂缓`：产品决定当前版本不建设写入能力
- `已裁撤`：产品决定移除该能力，相关代码与测试已清理
