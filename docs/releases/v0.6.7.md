# 森特智行 v0.6.7 智能截图记账兼容版

## 定位

v0.6.7 在 v0.6.6 的微信自然语言确认安全合同上，兼容用户原有 iCost 智能截图记账的轻量交互。快捷指令继续沿用“截图、裁剪、OCR”三个原动作，只把最后的 iCost App Intent 写入替换为森特智行待确认提交。

## 修复内容

- 新增专用的截图 OCR 提交接口，不再要求用户逐层选择收支、类别和子类别。
- 后端根据 OCR 与既有费用分析结果预选餐饮、住宿、交通、招待或其他；无法可靠识别时安全回落到“其他”。
- iPhone 提交成功后保持静默并等待小小微信草稿；服务端返回错误时才显示明确失败提示。
- 新增严格转换器，只接受恰好包含截图、裁剪、OCR、iCost V7 四个动作的参考快捷指令，并保证转换后不残留 iCost 写入动作。

## 人工确认边界

- 截图提交只创建待确认记录，不直接产生财务写入。
- 小小只接受原文精确的“确认”、以“修改”开头的字段修改和原文精确的“取消”。
- 六位码、宽泛肯定词、带标点或空白的确认不写账。
- 只有已成功送达的当前版本微信草稿可以确认；幂等重放不会重复记账。

## 凭据与发布边界

- 个人签名快捷指令中的账号密码只用于 HTTPS inline 认证，认证后从业务载荷剥离，不写入数据库、审计、日志、Git 或发布归档。
- 项目所有者于 2026-08-22 明确要求本次直接切换生产且不同步 GitHub。本地仍必须通过完整测试、秘密扫描、exact-commit 不可变打包、生产备份、preflight、受控 cutover 与 HTTPS smoke。
- 本次只切换 backend、frontend 和 weixin-agent 三个项目服务；共享 Caddy、account-vault、Qingyang 和 Mihomo 只读核验且不得重启。
