## 变更内容

- 客户资料支持维护医院官网公告页及对应公共资源交易平台来源，监测任务按客户配置来源执行；医院站点解析保留页面内公告链接与时间等来源信息。
- 招标监测通知接入 PushPlus 投递队列，保存发送状态、重试信息和幂等标识；业务站内通知可在系统内查看和处理。
- 微信 Clawbot 保留给记账流程使用；招标监测不依赖微信会话时效，通过 PushPlus 发送。
- 系统设置页新增 PushPlus 凭据配置、更新与清除入口；只显示脱敏状态，不回显 Token 或 AccessKey。缺少任一凭据时不启动自动推送调度，管理员补全后再启用。
- 数据库迁移向前兼容；生产环境无须通过 SSH 或环境文件传递 PushPlus 凭据。
