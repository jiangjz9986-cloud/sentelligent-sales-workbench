# 森特智行 v0.7.0 小小助手：招标微信推送与白天轮巡窗口

## 目标

- 把医院招标监测的通知通道从 PushPlus 切换为微信助手"小小"主动推送（v0.7 全能助手系列第一步）。
- 轮巡限定在白天 9–20 点（Asia/Shanghai）活动窗口内，配合每 2 小时间隔实现"白天定时增量刷新，有新才推"。

## 主要变更

- 新增 `backend/src/hospitalTender/weixinNotifier.js`：把每轮新增高相关公告组装为有界纯文本分片（每条消息最多 20 条公告），经既有微信确认 outbox 入队；幂等键 `hospital-tender:cycle:{n}:chunk:{i}:{内容哈希}`，同轮重放不重复推送；owner/会话在调用时解析，未绑定投递目标 fail-closed。
- outbox 渲染扩展 `payload.kind = "hospital_tender_notice"`；快捷记账各 kind 渲染与未知 kind 的 fail-closed 行为完全不变。
- `server.js` 装配：微信投递就绪时招标通知走小小（通知状态 `provider=weixin`），否则回退 PushPlus；`notificationEnabled` 同步两通道。
- 迁移 `0026_hospital_tender_active_window`：`hospital_tender_scheduler_state` 新增 `active_start_hour`（默认 9）/`active_end_hour`（默认 20）；调度器窗口外把 `next_run_at` 跳到下一窗口起点并记 `waiting`；`--force` 手动运行不受限。
- 调度器 PATCH API 支持 `activeStartHour`/`activeEndHour`，非法组合（start>=end、越界）422 fail-closed；窗口或间隔变更即时重启定时器。

## 边界

- 不改采集器、游标、批量、快照与匹配核心；不改快捷记账确认合同；不新增前端界面（窗口/间隔用既有调度 API 配置）。
- 推送 payload 与日志不含 token、密钥或公告正文之外的内容。
- 按项目所有者授权走本地 exact-commit 生产发布，不同步 GitHub。

## 部署后配置

- 将轮巡间隔设为每 2 小时：`PATCH /api/hospital-tenders/scheduler {"intervalMinutes":120}`（窗口默认 9–20 已随迁移生效）。
