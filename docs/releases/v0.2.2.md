# 森特智行 v0.2.2

## 状态判定

本文件记录 `codex/project-sync-release` 分支上的开发候选，不是已发布版本。`VERSION`、根项目、后端、前端及对应锁文件元数据已经切换到 `0.2.2`；`v0.2.2` 尚未创建 tag、GitHub Release 或生产 release 目录，也没有部署到服务器。

`v0.2.1` 仍是生产基线。此次候选开发只在本地工作树进行，没有连接生产环境，不改变线上版本。

## 目标

在现有 Apple Design 风格工作台内，收紧快速记录、客户详情、移动端浏览器兼容性和发布安全边界。所有业务操作继续保留真实数据链路、显式写入和可审计结果，不用演示数据掩盖失败。

## 候选改动范围

### 快速记录和响应式工作台

- 总览、侧栏和子页面入口统一经过导航状态函数，重新进入快速记录时默认选择语音。
- 移动端使用紧凑导航和公司图标，减少顶部占用；输入框、选择框和链接满足触摸尺寸，表单字号适配 iPhone Safari，保持内部滚动和无页面级横向溢出。

### 客户查询和维护

- 客户详情默认只读，查询不会直接进入编辑状态。
- 修改、取消和删除是独立操作；取消不写回，删除需要确认，并处理 Escape、重复点击、忙碌和错误状态。
- 集成验收同时检查 UI 状态、请求次数和重新加载后的后端持久化结果。

### 浏览器和服务安全

- 增加 Playwright WebKit 流程，覆盖 iPhone Safari 等价场景下的登录、语音兜底、客户维护和退出。
- 静态服务增加 CSP、HSTS、`nosniff`、frame denial、Referrer-Policy 和麦克风/地理位置权限策略；生产 HTTPS 仍由现有共享 Caddy 负责，不在本候选中改动共享配置。

### 生产验证和发布门禁

- HTTPS 冒烟脚本固定精确 origin、stdin 密码输入、手动重定向、UUID 运行标记、原子 `0600` 报告和 finally 登出。
- 清理脚本绑定真实 SQLite 文件身份，只允许固定表和关系，拒绝伪造 ID、错误数据库、并发运行和无关依赖残留。
- release manifest、源码/构建/迁移哈希、服务入口和远端 tag 统一复核；CI 和 Release workflow 执行 Chrome 集成及 WebKit 门禁。
- 受控 cutover 只允许操作 `sentelligent-backend.service`、`sentelligent-frontend.service` 和 `sentelligent-weixin-agent.service`，并保留回滚、PID 与共享 Caddy 配置快照。

## 销售决策 Agent V1 边界

《森特智行复杂型 B2B 销售决策 Agent V1》规格已经完成并通过规格级检查，内容包括证据/推断/假设/未知分离、客户价值发现、决策链、阶段门槛、100 分评分与封顶规则、行业规则、合规红线、JSON 合同和 eval 案例。

当前不能把它描述成已上线功能：完整规格尚未拆分为核心 system prompt、场景 playbook、行业规则包、JSON Schema 和评估集，也尚未接入现有 `backend/src/modelAnalysis.js` 的 DeepSeek 运行时。现有快速记录 DeepSeek 分析保持独立，关键写回仍要求人工确认。
