# 森特智行 v0.12.1

## 发布身份

| 字段 | 值 |
| --- | --- |
| 版本 | `0.12.1` |
| 发布类型 | Service Worker 与滚动修复补丁 |
| 升级基线 | `3370b9451f390cfcfa56bf8c4eb9b2df31c43a68` |
| 发布提交 | 以本文件对应的最终 40 位 exact commit、tag 和 release manifest 为准 |
| 回滚点 | 已验收的 `v0.12.0` immutable release |

## 修复内容

- 生产 PWA 使用 `autoUpdate`，生成的 Service Worker 启用 `skipWaiting` 和 `clientsClaim`，新 Worker 安装后自动接管已有标签页。
- Service Worker `controllerchange` 只在当前页面生命周期内触发一次 reload；不再使用跨更新长期存在的 `sessionStorage` guard。
- 保持 `.content` 为工作台桌面垂直滚动根，覆盖桌面滚轮、嵌套滚动链和移动布局约束，避免旧 Worker/CSS 继续控制未更新的标签页。
- CI 浏览器安装同时准备 Chromium 与 WebKit，补充生成 `sw.js` 的自动接管断言。

## 验证范围

- 根发布测试、完整历史密钥扫描、后端全量测试通过。
- 前端 `qa:local`、`qa:integration`、滚动专项、客户导入六视口验收和 `qa:webkit` 通过。
- 真实浏览器验收范围为 Mac Google Chrome；暂不把手机 Safari 网页验收写成通过。
- 微信“小小”助手只做已打开客户端中的只读、预览和取消路径检查；任何真实发送都必须在发送前重新确认目标会话、具体消息和业务影响。

## 生产边界

本补丁必须使用新的 immutable release 目录和新的 exact commit。生产切换只重启 `sentelligent-backend.service`、`sentelligent-frontend.service` 与 `sentelligent-weixin-agent.service`，保留共享 Caddy、旧 release、数据库备份和既有 v0.12.0 evidence；不得读取 iCloud 中的密钥或资料。
