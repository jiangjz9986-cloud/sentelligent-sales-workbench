# Sentelligent v0.4.1

This patch release corrects the production preflight and cutover service-surface contract discovered during the v0.4.0 deployment rehearsal.

## Change

- Accept the existing hardened `PrivateTmp=true` setting.
- Allow the frontend service to read only `config/frontend.env`.
- Allow the WeChat worker's fixed non-secret `HOME` assignment.
- Keep backend/weixin bound to the same private backend environment file and reject all other execution-surface additions.
- Accept the CentOS 7 singular `EnvironmentFile=` output key, while rejecting additional or alternate environment files.

## Release and production evidence

The final commit, annotated tag, GitHub Release asset SHA-256, production release directory, preflight report, cutover report, HTTPS smoke report, and browser acceptance timestamp must be recorded after the guarded deployment. No secret values, tokens, passwords, cookies, private keys, database contents, or business attachments belong in this file.
