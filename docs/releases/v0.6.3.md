# 森特智行 v0.6.3 候选说明

## 定位

v0.6.3 是从 v0.6.1 生产基线继续收敛的完整候选，重点完成三条内部链路：小小统一助手、森特本地快捷记账的微信复核闭环、医院招标公开来源自动轮巡。

## 已纳入

- 小小助手：战情/客户/商机/项目分析、拜访草稿确认、动作风险、行程、差旅和周报只读摘要；执行真源仍是 registry、policy 和 router。
- 快捷记账：iOS Token → 森特本地识别草稿 → 微信小小复核/修改 → 确认后创建森特费用和付款记录；结构化确认码冲突拒绝，accepted 条目可对账恢复。
- 医院招标：公开来源采集、每小时一批 10 客户、稳定游标、快照/运行/锁持久化、重启恢复、来源健康和 PushPlus 高相关批次通知。
- 系统配置：独立页面生成/轮换本地记账 Token，DeepSeek Key 只在后端加密保存并由运行时密钥提供器读取。

## 明确不包含

- 不包含 biubiu、轻氧桥接、跨系统凭据或远端记账写入。
- 不自动修改客户、商机、销售阶段或财务审批状态；所有财务写入仍需确认。

## 发布门禁

候选必须通过 backend 全量、前端本地/集成/WebKit、生产 preflight/cutover/release、全历史 secret scan、不可变发布包和生产合成 smoke。真实医院站点采集与 PushPlus 通知只在生产授权窗口执行，失败时保留当前轮巡批次并可重试。
