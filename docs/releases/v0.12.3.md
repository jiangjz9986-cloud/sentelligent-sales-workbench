## 修复内容

- v0.12.2 生产 HTTPS smoke 的 quick-record preview/analyze 偶发返回 `mock_model_fallback`；受控探针确认供应商可返回 HTTP 200 且包含大量 `reasoning_content`，但最终 `message.content` 为空。
- 快速记录是有界 JSON 抽取，不需要开放式推理。仅该 DeepSeek 请求显式发送 `thinking: { "type": "disabled" }`，避免推理内容耗尽 completion 预算，同时保留 3200 token 输出上限、JSON mode、原超时和确定性 fallback。
- `callChatCompletion` 的 thinking 参数为可选项；周报、方案、手工建议、行程与拜访温度等既有调用不携带该字段，销售决策继续保留原有独立推理和超时策略。

## 不变边界

- 不修改 shared sales-workbench API contract、`0042–0045` 迁移、数据库 schema、owner 隔离、action/risk 写回、客户导入或医院招标 bridge。
- PushPlus 保持退役；医院招标、主动助手和运维告警的现行外部通知只进入微信 Clawbot durable outbox。
- 生产切换只允许重启 backend、frontend 和 weixin-agent；共享 Caddy 与 Qingyang 服务保持受保护。
- 不读取 iCloud。生产 SSH 只使用用户提供的桌面密钥。
- iPhone 真机验收已取消，不属于本次门禁，不记录为通过；发布后验收范围是 Mac Google Chrome、页面滚动和微信 Clawbot。
