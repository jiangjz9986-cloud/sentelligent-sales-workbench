# Sentelligent v0.5.1

## Scope

v0.5.1 is a production-gate compatibility patch for the persistent Clawbot assistant release. It does not change business APIs, database migrations, assistant tools, or the personal natural-week reimbursement workflow.

## Fix

v0.5.0 added the independent machine/confirmation-secret preflight check, but the guarded cutover script still required the older 24-check report. A valid v0.5.0 production report could therefore be rejected immediately before service mutation. v0.5.1 binds both sides to the same exact 25-check contract and adds a regression test for the accepted 25/25 report.

## Deployment boundary

This release must be installed into a new immutable root-owned release directory from the GitHub Release archive. The existing production release and all unrelated services remain unchanged until a fresh backup, migration rehearsal, exact 25/25 preflight, controlled three-service cutover, post-cutover HTTPS smoke, and real browser/WeChat acceptance pass.

## Evidence policy

Record only non-secret commit IDs, tags, archive digests, release/evidence paths, timestamps, check counts, and protected-service fingerprints. Never record credentials, cookies, private keys, model output, database rows, or business attachments.
