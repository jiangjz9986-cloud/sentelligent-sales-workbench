# 森特智行 v0.5.7

## 目的

v0.5.7 修复真实微信直聊更新的第二个兼容边界。上游会在直聊消息中携带空字符串 `group_id` 占位字段；旧版适配器把“字段存在”误判为未识别群聊信号，导致消息在入站规范化阶段失败并持续重试。v0.5.6 已修复的 19 位数字 `message_id` 精度问题继续保留。

## 修复边界

- 仅把 `undefined`、`null` 和空字符串的群聊占位字段视为无信号；任何非空 `group_id`、`room_id`、`chat_type` 或 `is_group` 仍 fail-closed。
- 保留私聊默认、显式群聊元数据、sender/时间戳/item 校验、delivery key 和 64 位 canonical ID 边界。
- 新增真实形状回归测试；不新增路由、工具、数据库迁移或前端行为。
- 不把 sender、密码、Token、Cookie、私钥、数据库内容或微信消息正文写入仓库或证据。
