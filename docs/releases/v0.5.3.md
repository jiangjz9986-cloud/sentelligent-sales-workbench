# Sentelligent v0.5.3

## Scope

v0.5.3 is a local release candidate combining the WeChat Clawbot confirmation closure, descriptive assistant capability metadata and bounded project analysis, and QA/process hardening. It is not a GitHub Release, cloud upload, production cutover, or real-device acceptance result.

## WeChat confirmation closure

- The reviewed vendored `weixin-agent-sdk@0.5.0-sentelligent.1` supplies bounded sender, chat-scope and delivery metadata. Delivery identity is opaque and derived with the machine token; production remains private-chat only and rejects group traffic.
- A pending write is bound to its persisted tool and arguments, owner, sender, channel and private conversation. The user confirms by replying in that same chat with exactly six ASCII digits; `取消` and `重发确认码` are accepted only as exact commands.
- Codes are shown once and only their HMAC is persisted. Five incorrect attempts lock an action; one-time execution leases and stable tool-run identities cover retries, concurrency and crash recovery.
- Token rotation must stop the old worker, drain and seal its polling cursor, and only then enable the new token. New and old cursors must never consume concurrently.

## Capability metadata and project analysis

The capability catalog is descriptive metadata: readiness, tool/API mappings, dependencies, integration points, confirmation level and source references. The project-analysis helpers are bounded pure functions that classify open/closed actions and risks while retaining source references. These additions do not transfer executable ownership from the agent registry, tool registry, router or server policy, and do not imply production readiness.

## QA hardening

Browser and integration QA now use owned child-process identities, bounded lifecycle waits, explicit `already_closed` terminal handling and fail-closed cleanup reporting. macOS portability and synthetic secret-scan/release fixtures were tightened without changing historical production evidence.

## Release boundary

All local and isolated checks for this tree identify a v0.5.3 code candidate only. Production facts remain those in the existing deployment evidence (`v0.4.4`); v0.5.3 has not been deployed. A separately authorized release, fresh preflight, controlled cutover, HTTPS/browser checks and real WeChat device post-check are required before any production claim.

## Evidence policy

Record only non-secret commit IDs, tags, archive digests, evidence paths, timestamps and check counts. Never record tokens, passwords, private keys, cookies, confirmation codes, model output, database rows or business attachments.
