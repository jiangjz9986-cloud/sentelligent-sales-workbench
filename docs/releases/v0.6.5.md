# 森特智行 v0.6.5 直接生产候选

## 定位

v0.6.5 将现网已具备但未形成完整公开发布链的能力，与最新安全修复重建为一个可审计的本地 exact-commit 候选：小小销售上下文、医院招标工作台、差旅报销增强，以及 iOS 快捷记账到微信六位确认码和可靠回执的闭环。

## 已纳入

- 小小：持久化客户/商机上下文、拜访实体关联、限界项目卡、真实来源周报和报销摘要。
- 医院招标：分页、搜索、筛选、重点机会、新鲜度、运行反馈、来源健康和 PushPlus 状态，含移动端 44px 可访问控件。
- 差旅报销：六字段账本、替票组合、安全图片/PDF 预览、分辨率门禁、费用清单和多页发票打印。
- 快捷记账：V7 设备配对、15 个合法收支目录、六位 HMAC 确认码、持久化微信 context、耐久 outbox、delivery scope、accepted/rejected 回执对账，以及 Web/微信并发终态保护。

## 安全与系统边界

- “确认”等自然语言不能入账；只有同一 owner、sender、conversation 的最新六位 ASCII 确认码有效。
- 财务写入和回执投递解耦：写入成功后即使进程中断，也由固定幂等键和后台对账补发回执，不重复记账。
- 不包含 Qingyang 运行时桥接或跨系统记账；仅为历史迁移兼容保留旧 schema 字段。
- 模型输出仍是预览或待确认草稿，不自动修改客户、商机、销售阶段或财务记录。

## 直接生产发布例外

项目所有者于 2026-08-22 明确授权：因 GitHub Actions 用量上限，本候选不再推送、合并或发布到 GitHub。身份链改为本地干净提交、完整本地门禁、本地注释标签、exact-commit 不可变归档、release manifest、独立 SHA-256 和生产 evidence。

该例外不放宽生产门禁。发布前必须完成完整历史密钥扫描、发布工具、后端、前端、Chrome 和 WebKit；生产必须完成在线一致备份、迁移演练、fresh preflight、只切换三个项目服务、post-cutover preflight、HTTPS smoke 和保护服务不变性核验。未完成上述证据前，本文件不表示已部署。
