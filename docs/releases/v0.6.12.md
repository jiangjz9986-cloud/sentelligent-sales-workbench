# 森特智行 v0.6.12 小小请款结算独立升级版

## 定位

v0.6.12 以生产 `v0.6.11` 的精确提交为唯一基线，只启用小小“请款结算与多退少补”只读预览。旧聚合 PR、其他财务 Agent 和“整理报销与记账快捷指令”会话的未提交内容均不进入本候选。

## 功能范围

- 服务端仅在已绑定 owner 与财务微信发送者完全匹配的本人私聊中，查询同一自然周的请款、到账、费用、付款资金来源和票据覆盖事实。
- 固定按“非公司直付的可报销金额 - 已收到请款金额”计算预览方向，显示公司应补、个人应退或平衡。
- 异常字段、记录截断、资金来源不明、票据未覆盖和缺少请款事实均会生成明确的人工复核阻塞项；缺少显式请款事实时不推断方向和金额。
- 支持“小小”中的“请款结算”“请款汇总”“多退少补”以及显式 `advance-settlement.preview` 路由。

## 财务安全边界

- 只生成带服务端证据快照哈希、来源可追溯的人工核对预览；本版不接受“确认”写入，不创建退款或补款流水，不修改费用、付款、请款金额或状态。
- 不调用模型推测金额、方向或缺失证据；owner 映射为空、跨 owner 查询或事实不完整时 fail-closed。
- 微信群聊、第二个普通 allowlist 发送者和未完成财务身份绑定的请求都会在读取结算数据、创建 tool run 或 agent run 之前拒绝，响应不泄露金额或记录是否存在。
- 同一事件成功重放只返回首次持久化结果；运行中或失败事件不会重新读取财务数据。费用与请款采用统一总量上限，超限即禁止输出确定方向。
- 差旅、付款凭证、发票和报销周汇总的版本化 Agent 继续保持禁用；快捷记账微信确认、幂等、终态守卫和 outbox 逻辑不变。

## 数据与发布边界

- 无数据库迁移；现有迁移文件与校验和保持不变。
- 无前端业务改动，但根目录、后端和前端包版本统一为 `0.6.12`，保证制品版本合同一致。
- 项目所有者要求不写入 GitHub，发布身份由本地干净提交、注释标签、确定性归档、manifest、SHA-256 和生产 evidence 固定。
- 发布前必须在生产数据库一致性备份副本上完成校验；切换前后重跑完整预检及 HTTPS smoke。只允许切换 backend、frontend 和 weixin-agent，共享 Caddy 及其他受保护服务不得改动。
