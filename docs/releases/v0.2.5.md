# 森特智行 v0.2.5

`v0.2.5` 修复快速记录 DeepSeek 分析在推理输出耗尽 completion token 预算时静默降级的问题。

## 修复

- 快速记录模型请求的 `max_tokens` 从 1200 调整为 3200，与生产中能够稳定完成结构化输出的销售决策预算保持同一量级。
- 严格 JSON 契约和确定性降级行为保持不变。
- 新增回归测试，直接校验发送给模型 provider 的 token 预算。

## 生产证据

`v0.2.4` 已在生产通过预检 `19/19`，HTTPS 冒烟为 `24/25` 且清理为 `clean`。唯一失败项为 `quick-record.preview`。无数据库写入的诊断请求确认：1200 tokens 返回 `finish_reason: length` 且 final content 为空；仅将预算改为 3200 后返回 `finish_reason: stop`，严格结构化解析通过。

## 变更边界

- 无数据库迁移。
- 无依赖升级。
- 不修改认证、Caddy、微信会话或共享服务配置。
- 回滚目标为上一已部署 immutable release，数据库不自动回滚。
