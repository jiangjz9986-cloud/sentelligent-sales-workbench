## 变更内容

- 医院招标推送设置页仅保留 PushPlus Token；后端配置、API 合同和自动调度不再要求 AccessKey。
- 移除 AccessKey 送达结果查询与轮询。PushPlus “已受理”仅代表服务端接受请求，不表示最终送达。
- 清除 Token 时停用招标自动轮巡，并清理遗留的加密 AccessKey 设置记录；不影响微信 Clawbot 记账链路。
- 不新增数据库迁移，保留既有历史迁移定义。

## 验收

- 后端全量测试、前端设置与 API 测试、Vite 生产构建及 Chrome 集成 QA 均通过。
- 正式 tag 对应的 Release workflow 仍将执行完整发布测试、浏览器测试并生成不可变制品；生产切换以制品校验、新鲜预检、部署后 smoke 与 Chrome 页面验收为准。
