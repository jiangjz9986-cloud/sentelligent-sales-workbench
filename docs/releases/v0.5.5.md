# 森特智行 v0.5.5

## 目的

v0.5.5 是微信入站兼容性补丁。真实微信上游将服务端 `message_id` 作为安全整数返回，而旧版 vendored SDK 只接受字符串，导致消息已被拉取却在规范化阶段失败，无法进入助手和回复流程。

## 修复边界

- 安全整数型 `message_id` 在校验后转换为字符串。
- 上游 ID 采用 `message_id > msg_id > client_id` 的明确优先级；只有缺少 canonical `message_id` 时才比较备用 ID，冲突继续 fail-closed。
- 保留 sender、时间戳、消息项、控制字符、长度、私聊边界和 delivery key 校验。
- 仅修改 vendored WeChat adapter 及其回归测试；不新增工具、路由、数据库迁移或前端行为。
- 不把 sender、密码、Token、Cookie、私钥、数据库内容或微信消息正文写入仓库或证据。

## 验收边界

本文件在候选阶段不宣称 GitHub Release 或生产部署。候选必须通过：

1. 本地 secret scan、脚本测试、后端全量测试、前端 QA、WebKit QA 和 `git diff --check`；
2. GitHub tag 对应的不可变归档、manifest 和 SHA-256 校验；
3. 服务器新鲜 `25/25` preflight、受控 cutover、HTTPS smoke 与清理；
4. 真实微信 `/clear` 回复、worker 无持续错误、cursor 正常推进。

生产基线在全部证据完成前仍为 v0.5.4。
