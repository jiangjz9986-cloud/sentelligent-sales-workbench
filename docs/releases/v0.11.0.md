- 整合招标命中转商机、拜访温度建议、发票逾期升级、统一 AI 结果卡和快速记录确认预览等 v0.11 功能。

- 统一限制 `MODEL_TIMEOUT_MS` 为 `1–120000` 毫秒，并让生产预检复用同一上限，避免 Node 定时器溢出导致近似立即超时或异常退出。
- 严格校验 `AI_ANALYSIS_MODE` 和 `MODEL_BASE_URL`；模式值会归一大小写和首尾空白，模型 URL 的首尾空白、凭据、查询串、片段和不安全协议会在配置阶段失败。
- 保留人工确认、owner 隔离、来源引用和历史只读边界。
