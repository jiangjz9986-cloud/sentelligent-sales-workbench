## 变更内容

- 最近微信记账回执是账本辅助信息；如果一条已接受的历史回执关联费用或付款已失效，跳过这条回执，避免整个自然周账本因历史孤立数据而返回 HTTP 409。
- 单条回执的直接读取仍保留冲突保护；首次周账本读取失败时页面明确显示“同步失败”，409 提示包含错误码和请求编号。
- 增加真实 React 页面 Chrome 回归：首次读取冲突后成功时账本正常显示；持续冲突时页面显示失败态和最终请求编号。
