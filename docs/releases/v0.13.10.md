## 变更内容

- 未手动选择发票或替票的记账，不再因自动匹配、未接受候选、无票确认或已保留的凭证导入历史而被误拦删除。
- 手动确认的发票匹配和用户已接受的替票候选仍保护关联；删除时自动匹配撤销、未接受候选过期、无票确认撤销，并重算发票仓库可用状态。
- 保留导入与凭证来源作为历史记录；删除冲突只返回确切的已确认关联，前端显示具体说明。

## 验收结果

- 本地 `npm run qa:full` 完成；发布/部署测试、安全扫描、AI Platform、Backend、前端本地 QA、Chrome 集成与滚动/客户导入/删除回归、WebKit 验收均通过，密钥扫描无 findings。
- Chrome 删除专项通过 `1/1`：仅在确有已确认票据关联时阻止删除；没有手动匹配的导入历史不会误阻断删除，冲突提示不重复发出删除请求。
- 正式制品、生产预检、切换、postflight 和 HTTPS smoke 结果待本次正式发布后补录；这些线上门禁完成前不表示 v0.13.10 已上线。
