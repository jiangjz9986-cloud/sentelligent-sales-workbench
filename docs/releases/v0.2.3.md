# 森特智行 v0.2.3

`v0.2.3` 是 `v0.2.2` 生产验收中发现的销售决策模型边界 hotfix。候选发布前不预填 tag、GitHub Release、生产路径或验收结果；这些事实只在对应操作实际完成后补录。

## 修复

- `stage.current` 改为服务端所有：由已存商机阶段映射成 `sales-decision-v1` 规范枚举，再进入模型响应校验。
- DeepSeek 即使回显 `qualification` 等业务阶段名，也不会因此丢弃其他合法结构化分析并降级为 `mock_model_fallback`。
- 模型建议阶段 `stage.recommended` 和其他合同字段继续严格校验，非法结构仍安全降级。
- 生产切换脚本的停服监听检查改用可移植 awk 变量名，CentOS 上不再因语法错误跳过 8088/8897 端口关闭验证。

## 变更边界

- 无数据库迁移。
- 无依赖升级。
- 不修改认证、Caddy、微信会话或共享服务配置。
- 回滚只重新固定三个项目 systemd 单元到上一已验收 immutable release；数据库不自动回滚。

## 发布门禁

- 根目录、后端、前端及部署测试全部通过。
- 完整 Git 历史敏感信息扫描通过。
- GitHub Release 归档 SHA-256 与 manifest commit 一致。
- 生产预检 `19/19`。
- HTTPS 冒烟 `25/25`，审计清单、注销和物理数据清理均通过。
- 浏览器登录与核心业务流程通过，受保护 PID 与 Caddyfile SHA-256 保持不变。
