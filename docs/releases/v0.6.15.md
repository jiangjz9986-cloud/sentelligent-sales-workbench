# 森特智行 v0.6.15 小小微信图片记账

## 定位

本版以生产 `v0.6.14` 的 exact commit `e124c7a501a02a47ed6e2f24ffe799cbbcecd762` 为基线，将记账入口统一为本人向“小小”微信助手发送图片或文字。iOS 快捷指令、iCost 写入、Token 页面、签名工具和发布资产均退出当前产品流程。按项目所有者授权，本版不写入 GitHub，生产身份由本地 exact commit、不可变归档、manifest、SHA-256 和服务器 evidence 共同确认。

## 业务合同

- 本人私聊可发送单笔付款凭证、包含多笔交易的列表截图、收入/支出文字、借款到账信息、发票图片或发票 PDF；其他 sender 和群聊不能创建财务草稿。
- OCR/AI 为每笔交易生成独立草稿；多笔列表以金额列坐标拆分。缺少发生日期时不以收件时间冒充，周期保持待确认。
- 小小按固定格式返回“编号、类型、金额、费用类别、备注、周期、AI 状态”，编号按收件时间生成，周期按发生日期所在周一至周日计算。
- 只有引用当前已送达草稿的本人自然语言回复才可确认、修改或取消；确认前不创建正式费用、付款或借款收入。
- 支出的可报销金额等于消费金额。没有可用借款时按个人垫付；借款只有确认到账后作为收入入账，并沿用现有自然周分配与余额展示合同。

## 数据与发布边界

- 付款凭证保存原始摘要与字节信息，同时生成压缩附件；同一原图拆出的多笔记录复用内容寻址 Blob，重发相同微信事件或相同文件不会重复建账。
- 发票按金额优先匹配当前自然周的唯一条目；唯一跨周候选只在 31 天窗口内自动关联。多个同额候选、超出窗口或识别不完整时进入人工复核。
- 旧 `/api/integrations/shortcut/*`、iCost webhook 和 iCost Token 路径无条件返回 `410 LEGACY_BOOKKEEPING_RETIRED`；旧 handler、认证、Token、配对、预览、提交和重试实现已删除，前端不再暴露入口，发布环境拒绝旧变量。
- 已删除快捷指令/iCost 构建、转换、签名、验证脚本和 `.shortcut` 资产。历史迁移、表名、审计 action 与仓库内部旧命名暂时保留，确保既有财务记录可读取和回滚；本版没有新增数据库迁移。
- “整理报销”会话的数据结构与普通手工报销流程不在本版中重构；生产切换仍只允许项目 backend、frontend、weixin-agent 服务，不影响共享服务。

## 验收门禁

- 后端全量、微信图片记账/发票定向测试、前端完整 `qa:local`、发布测试、生产预检测试、完整 Git 历史密钥扫描及 `git diff --check` 必须全部通过。
- 发布包、生产预检、数据库备份与恢复演练、切换前后检查及 HTTPS smoke 必须在真实服务器取得当次证据后，才可标记为已部署。
