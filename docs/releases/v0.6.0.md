# 森特智行 v0.6.0 候选说明

## 定位

v0.6.0 把系统配置与医院招标监测从独立代码能力收口为主系统功能。当前文件描述本地候选，不表示 GitHub Release 或生产部署已经完成；现网仍为 v0.5.7。

## 主要变化

- 新增独立系统配置页，支持 iCost Token 一次性生成/轮换和 DeepSeek API Key 加密保存。
- 浏览器、微信及持久化助手统一通过服务端密钥提供器调用模型。
- 医院招标监测使用内置公开来源采集器，不要求使用者配置第三方招标 API。
- 默认每 60 分钟处理 10 个客户；每轮只采集一次公开快照，后续批次复用并合并客户匹配。
- SQLite 保存轮巡启停、批量、游标、轮次、快照、运行记录、锁、最近/下次运行和安全错误。
- 页面显示轮巡进度、本批新增高相关公告、来源健康、公告详情和客户匹配证据。

## 安全与业务边界

- 密钥明文不进入普通查询、日志、审计、浏览器存储或 Git。
- 只有登录用户和 CSRF 校验通过的写请求可以修改配置或手动触发下一批；采集机器身份不能读取轮巡状态或调用控制入口。
- 招标情报只读，不自动创建或修改客户、商机、动作、风险或销售阶段。
- 批次部分失败不推进游标；服务重启、客户新增/删除和锁冲突按持久化状态恢复。

## 当前验证

- 后端全量测试通过：712/712。
- 根级部署测试通过：222 个通过，2 个 Windows 专用测试跳过。
- 前端 API、医院招标页面契约和生产构建通过。
- 完整 Git 历史密钥扫描通过，无发现。
- 本机缺少 Chrome/Edge，`qa:local` 在 StageStrip 浏览器依赖处停止；该项不是生产验收证据，发布前仍需补 Chrome/WebKit 和线上验证。

## 生产前置

- 配置 `SETTINGS_ENCRYPTION_KEY`。
- 将 `HOSPITAL_TENDER_PYTHON` 指向生产服务器上规范化、非符号链接、无 setuid/setgid 与文件 capability、后端服务账号可执行但不可改写的 Python 3.11+ 绝对路径。
- 生产环境明确配置 `HOSPITAL_TENDER_AUTO_RUN=true`、`HOSPITAL_TENDER_INTERVAL_MINUTES=60`、`HOSPITAL_TENDER_BATCH_SIZE=10`；`v0.6.0` 迁移会持久化固定的 `60/10` 状态，之后以 SQLite 轮巡状态为准。
- 完成不可变归档、数据库迁移演练、生产预检、受控切换、HTTPS smoke 和页面/微信回归后，才能把生产口径改为 v0.6.0。
