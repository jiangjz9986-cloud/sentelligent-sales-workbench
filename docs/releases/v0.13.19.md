## 变更内容

- 医院招标 Python 采集器子进程显式设置 `PYTHONDONTWRITEBYTECODE=1`，避免 Python 将 `__pycache__` 写进不可变 release 目录并破坏 manifest 文件清单校验。
- 增加 runner 环境合同测试，确认采集器继续使用无凭据环境且禁止 bytecode 写入。

## 验收

- 正式发布 CI 必须完成安全扫描、后端、前端、Chrome 集成和 WebKit 验收后才可部署。
