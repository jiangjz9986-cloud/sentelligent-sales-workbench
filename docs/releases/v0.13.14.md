## 变更内容

- 新增收入/支出费用分类目录，按账号和账本隔离，支持系统默认分类、自定义分类、子分类以及归档状态。
- 新增分类管理 API 和系统设置页面，支持列出、创建、更新、停用、恢复、查看归档分类；写入需要 CSRF、防并发覆盖的 `If-Match` 和审计记录。
- 记账写入、微信助手确认、分析和历史修订统一通过当前账号分类目录解析；停用分类不参与新记账解析，但同名历史分类仍可安全修订。
- 系统默认分类名称保持只读，避免破坏既有账本语义；系统分类仅允许维护子分类。
- 新增迁移 `0049_bookkeeping_categories`，采用加法兼容方式，不改写既有账本数据。
