| 字段 | 值 |

| 数据变更 | 不改写既有发票或费用数据；仅在新增或更新记账后确认唯一合规发票匹配 |
| 发布与部署身份 | 以最终提交、注释 tag、GitHub Release、manifest 和服务器 evidence 为准 |

## 变更内容

- 新增费用写入后的反向发票匹配：当发票已经在仓库、记账随后创建或更新时，自动按未覆盖金额、付款/开票日期顺序、自然周优先和 31 天窗口检索。
- 只有唯一精确且合规的候选才自动确认；同额多张发票、开票日在付款日前、超出日期窗口、替票费用和不完整金额继续进入人工复核。
- 直接记账接口和微信确认链路共用该能力；微信回执保持短格式，成功自动绑定时追加“已自动关联发票”。
- 保留现有发票状态、费用状态、匹配记录和微信附件写回边界；自动匹配失败不会回滚已完成的记账写入。
