# 森特智行 v0.7.4 小小微信回复卡片统一

## 目标

- 落实项目所有者真机试用反馈：小小的所有回复对齐记账消息的卡片版式——格式化、短、好扫（总蓝图 E+ 阶段，用户反馈驱动的插入版本）。

## 主要变更

- 新增共享渲染器 `backend/src/assistant/weixinCard.js`（`weixinCard/weixinValue/weixinClip/weixinShortId`）：`【标题】` + 每行一个 `标签：值` + 空行 + 一句操作提示；空值"待确认"、列表顿号连接、超长截断。
- 改造回复面：
  - 拜访记录：新增/修改/作废预览卡（`【小小提醒！新增一条拜访记录/修改拜访记录/作废拜访记录】`）、录入/更新/作废回执卡、记录列表卡与空态；旧三步流预览卡同步换版式并保留"回复录入"指引。
  - 客户：画像卡、建档/改档/删档预览卡（`【小小提醒！新建/修改/删除客户】`）、建档/更新/归档回执卡、候选消歧卡（`【找到多个客户】`编号列表）。
  - 其他：商机详情卡、战情总览卡、客户检索列表卡。
- 确认提示语简化：六位码卡两行（确认码 + 回复指引），轻确认一句（"请回复“确认”或“取消”"）；确认链 TTL/取消/重发/明文码不落库等安全不变量字节级不变（仅 text 拼装变化）。
- 去技术细节：回复不再含 UUID/乐观锁版本号/运行记录 ID，单据统一尾 6 位短码；摘要截断 160→80 字符。
- 零数据库迁移、零 API 合同变化；模型路由不变。
