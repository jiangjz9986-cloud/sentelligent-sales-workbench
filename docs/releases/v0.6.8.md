# 森特智行 v0.6.8 截图记账设备直连版

## 定位

v0.6.8 移除 iPhone 智能截图记账中的账号、密码常量和登录步骤。个人快捷指令只执行截图、裁剪、OCR 和 HTTPS 提交，提交成功后仍由小小发送微信草稿等待人工确认。

## 修复内容

- 新增账号绑定的设备直连截图接口 `/api/integrations/shortcut/bookkeeping-capture`。
- 快捷指令不再包含或发送 `account`、`password` 字段，改用一次绑定后生成的不可读设备身份；用户运行时无需输入、编辑或维护凭据。
- 保留旧 iCost 快捷指令的截图、裁剪与 OCR 文本包装，并将时间幂等键和 `source_id` 强制序列化为文本，避免 iOS 将变量作为富对象提交。
- 接口只接受严格 JSON、固定来源和账号绑定设备身份；无身份、无效身份、错误方法及额外字段均在写入前拒绝。
- 提交成功保持静默，服务端明确返回错误时才显示失败提示。

## 人工确认边界

- 截图提交只创建待确认记录，不直接产生财务写入。
- 小小只接受原文精确的“确认”、以“修改”开头的字段修改和原文精确的“取消”。
- 六位码、宽泛肯定词、带标点或空白的确认均不写账。
- 只有已成功送达的当前版本微信草稿可以确认；幂等重放不会重复记账。

## 凭据与发布边界

- 设备身份仅写入用户个人签名后的快捷指令，不写入源码、Git 历史、发布归档、日志或对话输出；个人快捷指令不得转发。
- 原有账号密码 inline 接口仅作为旧版本回滚兼容路径保留，V3 不调用也不携带其字段。
- 项目所有者于 2026-08-22 明确要求本次直接切换生产且不同步 GitHub。本地仍须通过完整测试、秘密扫描、exact-commit 不可变打包、生产备份、preflight、受控 cutover 与 HTTPS smoke。
- 本次只切换 backend、frontend 和 weixin-agent 三个项目服务；共享 Caddy、account-vault、Qingyang 和 Mihomo 只读核验且不得重启。
