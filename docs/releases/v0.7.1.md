# 森特智行 v0.7.1 记账确认唯一化与实时日志

## 目标

- 记账确认收敛为微信单一入口：网页不再提供任何"二次确认"操作面，避免双端确认口径漂移（v0.7 全能助手系列第二步）。
- 给记账全链路一个可对账的实时留痕视图：系统配置新增"记账日志"，覆盖服务端动作与关键客户端动作（打印/导出）。

## 主要变更

- 差旅工作台"小小待确认记账"改只读复核卡：保留原始文字折叠与识别摘要（日期/金额/用途/商户/分类 dl 展示），新增微信引用回复引导；删除确认入账/重新识别/拒绝按钮与可编辑表单。
- 移除跨周账目提示横幅与 Web 端确认后的跳转定位链路（`selectCrossWeekLedgerReceipts`、`locateRecentReceipt`、`refreshWeixinBookkeepingReviews`），周切换与保存费用的定位机制不变。
- 前端 API 客户端裁撤 `confirmWeixinBookkeepingReview`/`rejectWeixinBookkeepingReview`/`retryWeixinBookkeepingReview`；微信 worker 走的后端确认合同不变。
- 后端 `GET /api/audit-logs` 新增 `scope=bookkeeping`：服务端常量前缀白名单（`travel_expense.`/`travel_expense_advance.`/`travel_expense_document_inbox.`/`invoice.`/`shortcut_bookkeeping.`/`bookkeeping_client.`），未知 scope 422 fail-closed。
- 新增 `POST /api/bookkeeping/client-events`：事件白名单 `print_expense_list`/`print_invoices`/`export_expense_xlsx`；`weekStart` 必须 `YYYY-MM-DD`、`itemCount` 必须 0–10000 安全整数，其余字段丢弃；写入 `audit_logs`（`bookkeeping_client.*`，entityType `bookkeeping_client_event`）。
- 前端三处埋点 fire-and-forget：打印费用清单、打印发票、导出费用 Excel；埋点失败静默，不影响主功能。
- 系统配置新增"记账日志"子页（`/settings/bookkeeping-log`，子导航第 5 项）：每 10 秒轮询 scope 过滤的审计流水并提供手动"刷新"按钮，动作中文标签映射、HH:mm:ss 本地时间、单据短标识（referenceCode 或 entityId 前 8 位）、金额/日期/摘要提取、删除/拒绝/失败类动作红点标识。
- 修复 v0.6.28 遗留的 `setRecentLedgerReceipts` 残留调用（state 已删但两处 setter 调用未删）导致差旅页周切换时运行时崩溃的问题，由 Chrome 集成走查捕获。

## 边界

- 不改微信确认链路、快捷记账仓库与 outbox 合同；不改数据库 schema（无新迁移）。
- 审计日志只读展示，不提供任何回写、导出或清理操作；日志内容不含密钥、附件字节或发票原文。
- 按项目所有者授权走本地 exact-commit 生产发布，不同步 GitHub。
