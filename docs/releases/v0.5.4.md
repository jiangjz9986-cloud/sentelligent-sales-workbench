# 森特智行 v0.5.4

## 目的

v0.5.4 是 v0.5.3 的生产启动兼容热修复。现有生产环境尚未绑定真实微信 sender，因此 `WEIXIN_ALLOWED_SENDER_IDS` 为空时允许服务启动；入站边界仍拒绝所有 sender，直到运维配置真实 sender ID。

## 边界

- 不改变 v0.5.3 标签或其 GitHub Release。
- 不新增微信工具、路由或数据库迁移。
- 不把 sender、密码、令牌、Cookie、数据库内容或业务附件写入仓库或证据。
- 生产发布必须重新执行完整本地门禁、不可变包校验、25/25 预检、受控切换、HTTPS smoke 和清理检查。

## 生产口径

发布和生产结果在完成后补写：完整提交、tag、GitHub Release URL、归档 SHA-256、生产 release 路径、预检/冒烟结果、清理状态和回滚证据。没有这些证据时，不宣称 v0.5.4 已上线。
