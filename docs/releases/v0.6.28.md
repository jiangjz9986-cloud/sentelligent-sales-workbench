# 森特智行 v0.6.28 差旅报销界面重设计

## 目标

- 依据浏览器全覆盖走查证据（本地隔离全栈 + 合成数据，桌面 1440×900 与移动 390×844）修复差旅报销模块的视觉与信息层级问题；不改任何业务行为。

## 主要变更

- 宽屏布局：账本/发票内容容器居中自适应，分区间距统一。
- 顶部与周条：工具条改为紧凑统计样式；自然周七格重排为"日期 / 城市 chip / 条数徽标"，未配置区域不再重复占位文案。
- 提示条：区域未设置与跨周账目提示收敛为细条样式，长编号等宽截断。
- 账目表：行高统一，凭证/发票状态改为浅底 pill，补票/查看操作统一按钮样式。
- 合计条：金额组（本周支出/可报销/借款收入/借款剩余，tabular-nums）、待办组（凭证缺失/发票缺失徽标）、操作组（打印/导出）三段分区。
- 小小待确认卡：原始文字三行折叠可展开；字段两列网格；英文错误码映射中文标签（缺发生日期/缺金额/缺费用类别/模型返回无效/需微信引用确认，未知码=待人工复核）；按钮组统一。
- 付款凭证区：去重复标题、块头一行化、上传控件收窄、收款方缺失回落显示费用商户。
- 发票页：仓库列固定宽、状态标签统一、预览容器规整。

## 边界

- 纯前端展示层：无 API、数据库迁移、业务逻辑或 data-testid 契约变更。
- 模型路由、微信链路、报销规则（可报销=消费金额）均不变。
- 按项目所有者授权走本地 exact-commit 生产发布，不同步 GitHub。

## 验收

- 后端全量测试通过；前端 `qa:local`、`qa:integration`（真实 Chrome）、`qa:webkit` 通过；根 `test:deploy`（含密钥扫描）通过。
- 部署仍要求不可变归档、fresh 备份、完整 preflight、受控 cutover、postflight 与 HTTPS smoke。
