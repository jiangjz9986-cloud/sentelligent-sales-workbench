# 森特智行 v0.6.11 本地统一升级版

## 定位

v0.6.11 以生产 `v0.6.10` 的精确提交为唯一基线，把安全系统配置、PushPlus 通知、非财务小小 Agent 与智能截图记账 OCR 修复合并为一个生产候选。所有能力统一经过同一不可变制品和一次受控切换，不由各开发会话分别部署。

## 合并内容

- 安全配置支持 DeepSeek、地图和 PushPlus 凭据，系统设置页展示脱敏状态与通知投递健康信息。
- 医院招标继续使用生产恢复版采集与调度逻辑，仅接入安全配置中的 PushPlus 通知能力。
- 小小新增固定 Agent 合同、持久化运行记录和销售上下文，覆盖销售决策、客户、商机、拜访采集、销售周报、动作风险、知识、行程和战情看板。
- 智能截图记账修复 OCR 纯文本传输、人民币金额识别和误判防护，并提供人工填写金额的兜底路径。

## 人工确认和财务边界

- 销售分析、周报、知识、行程和战情看板均为只读预览；拜访采集沿用显式确认后写入的既有边界。
- 截图记账提交只创建 owner-scoped 待确认草稿，不能绕过微信会话绑定、确认码、幂等和终态守卫直接写账。
- 本版明确不接入差旅 Agent、报销周汇总 Agent、发票 Agent、付款凭证 Agent 或请款结算 Agent；现网报销数据结构与共享 API 契约保持不变。

## 迁移边界

- `0019_shortcut_weixin_confirmation` 与 `0020_shortcut_income_entries` 保持生产原始内容和校验和。
- 新增 `0021_secure_settings_pushplus`、`0022_assistant_agent_runs`、`0023_assistant_business_context`。
- 发布前必须在生产数据库的一致性备份副本上完成迁移、`quick_check`、外键和迁移校验和验证；不得直接拿在线数据库做首次演练。

## 发布边界

- 项目所有者要求本次不向 GitHub 写入，直接部署生产；候选身份由本地干净提交、确定性归档、manifest 与 SHA-256 固定。
- 部署前后都要生成新的生产预检报告，切换后执行完整 HTTPS smoke 和清理核验；旧报告不能复用。
- 只切换 backend、frontend 和 weixin-agent 三个项目服务。共享 Caddy、account-vault、Qingyang 和 Mihomo 只读检查，不得重启或改写。
- 应用失败时回滚到切换前不可变 release；数据库恢复是独立高风险动作，不能随应用回滚自动执行。
