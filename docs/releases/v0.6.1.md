# 森特智行 v0.6.1

## 目的

v0.6.1 在保留 v0.6.0 医院招标、系统配置和安全设置的基础上，为 iOS 自有截图快捷指令提供账号级 Token 管理和只读验证边界，解决快捷指令无法确认 Token 是否有效、以及静态共享 Token 无法安全映射账号的问题。

## 发布内容

- 新增 `shortcut_webhook_tokens` SQLite 迁移（`0017`），只保存 Token 哈希、前缀、账号和使用元数据；`0014`–`0016` 保留给 v0.6.0 的既有迁移。
- 新增登录后的 Token 管理 API：
  - `GET /api/integrations/shortcut/tokens`
  - `POST /api/integrations/shortcut/tokens`
  - `DELETE /api/integrations/shortcut/tokens/:id`
- 新增公开只读接口：
  - `GET /api/integrations/shortcut/catalog`
  - `GET /api/integrations/shortcut/verify`
- Token 管理沿用 Cookie 会话和 CSRF；验证接口支持快捷指令的 explain 响应、限流和 no-store 缓存策略。
- 前端新增“快捷指令 Token”配置模块，支持一次性复制和撤销。

## 明确边界

本版本不注册 `POST /api/integrations/shortcut/bookkeeping`。有效 Token 的验证响应会返回 `tokenValid` 为 true、`bookkeepingReady` 为 false 和 `SHORTCUT_BOOKKEEPING_NOT_READY`；快捷指令因此停止在验证提示，不会截图、调用 AI 或创建任何财务记录。biubiu 到轻氧的跨系统写入需要单独的桥接凭据、契约和验收，不在本次发布中启用。

生产环境不允许 `SHORTCUT_WEBHOOK_TOKEN` 静态回退；数据库 Token 必须从登录后的系统配置页生成。完整 Token 只显示一次，泄露或更换设备时应撤销旧 Token 并生成新的。本次版本仍不改变生产服务，部署前需重新确认 v0.6.0 记录的 Python 3.11+ 运行时阻塞。

- 前端 routes/API/modules 测试和 production build
- 根目录 release、secret-scan、preflight/cutover 合约测试
- `git diff --check`

生产切换后的实际 release 路径、归档 SHA-256、数据库备份、预检、服务状态和线上验证结果追加记录在 [部署记录](../部署记录.md)。
