# 森特智行 v0.7.3 小小·拜访与快速记录 agent

## 目标

- 把拜访/电话/会议记录收进微信助手"小小"：`记一下：…` 一句话记录（轻确认），查历史免确认，改历史与作废走六位码（v0.7 全能助手系列第四步，总蓝图 E 阶段）。
- 补齐 `voided_at` 自迁移 0002 建列以来"有列无路"的作废能力缺口。

## 主要变更

- 四个快速记录工具注册进确定性编排器：`visit-capture.capture`（R1/affirm_language 轻确认）、`visit-capture.search`（R0 免确认）、`visit-capture.update`（R2/explicit_code）、`visit-capture.void`（R3/explicit_code）。写操作仅限与小小绑定的私聊，owner 由服务端解析。
- `记一下/记录一下/帮我记/快速记录/记拜访：…` 一步式捕获：同步 AI 分析（30s 超时静默降级确定性 fallback）→ 摘要卡（要点/客户匹配/待办建议）→ 回复"确认"写回。写回复用 quick_record 确认深写回链路（客户/商机/待办/风险联动），`source_channel='微信助手'` 直通周报素材路径不变。
- R1 轻确认复用记账"确认"交互的内部派生凭据模式，`pendingActionRepository` 零改动；编排器新增 `affirm_language` 确认分支，与六位码链共享 TTL/取消/重发语义。
- 与记账的歧义分流：金额（`N 元/块`）与记账词（记账/支出/收入/借款/报销/发票/付款）强信号让路记账链路；`记拜访：` 为绕开歧义的逃生门；拜访信号词（拜访/电话/会议/客户/医院/项目等）加权归属快速记录。
- 检索：`查（一下）…（今天/昨天/上周/本周/上月/本月/最近…）…的（拜访）记录`，中文口语时间窗解析（新增 `backend/src/assistant/spokenDate.js`，过去向），客户主语复用 v0.7.2 消歧器；候选卡带记录短码。
- 改历史：`把（那条/记录<短码>）的<字段>改成…`，字段白名单（发生时间/客户/商机/诉求/反馈/风险/建议/下一步），R2 预览卡 before/after + 乐观锁 `expectedVersion` 钉版。
- 作废：`作废/删除/撤销（那条）记录（<短码>）`，R3 六位码；首次为 `voided_at` 打通写路径，软作废可审计、读路径自动隐藏、重复作废冲突保留首次证据。
- 写路径抽取共享模块 `backend/src/quickRecords/quickRecordStore.js`（Web 与微信同一份 SQL/审计/版本冲突语义）；新增 `backend/src/assistant/quickRecordPendingPreviewProviders.js` 预览提供者。既有微信三步式 visit-capture 暂存流原样保留。
- 记账草稿并存回归合同：T-BK-1/2/3 在单元（shortcut-bookkeeping-safety）与 HTTP 集成两层固化——affirmed capture 无引用时 handlePending 让路、null capture+记账草稿并存让路、quoted 记账草稿优先（留在记账运行时应答 409"引用草稿非当前可确认版本"，真实入账由 HTTP 集成覆盖）。
- 零数据库迁移；模型路由不变（文本 deepseek-v4-flash；图片/PDF deepseek-v4-flash-vision-exp）。
