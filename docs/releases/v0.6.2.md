# 森特智行 v0.6.2

## 目的

v0.6.2 在 v0.6.1 账号级 Shortcut Token 边界上开放真实记账：用户继续只在 iOS 快捷指令填写一个森特账号 Token；后端按固定目录选择目标系统并完成幂等、租约、失败恢复和审计。

## 发布内容

- 新增 `0018_shortcut_bookkeeping_entries`，保存账号、选择分类、请求哈希、处理租约、本地差旅关联和轻氧远端状态；原始幂等键只保存 SHA-256 哈希，并按账号全局唯一。
- 注册 `POST /api/integrations/shortcut/bookkeeping`：
  - `出差报销` 支出经服务端分析后创建森特差旅费用和支付记录；信息不足时保留为 `review_required` 快捷指令记录和审计，并在森特网页“差旅费用 → 付款凭证 → 快捷指令待复核”提供 owner-scoped 列表、详情、补录确认、拒绝和重新识别入口。确认使用处理租约与幂等状态，只有成功确认才创建真实费用和付款记录。
  - `出差报销` 首期只开放支出；收入分类在目录中保留为空并由 API 拒绝，避免映射为不存在的本地收入模型。
  - `biubiu` 只通过固定 loopback 地址和服务端独立 bridge credential 调用轻氧；远端明确成功后才返回 `202`。
- `GET /api/integrations/shortcut/verify` 只有在账号 Token 有效且桥接配置完整时返回 `bookkeepingReady=true`。
- 生产 preflight 新增轻氧桥接配置和凭据隔离两项检查，候选版本门禁为 `27/27`。

## 安全与失败边界

- iOS 快捷指令和用户只持有森特账号 Token；轻氧 bridge credential 不进入响应、审计、快捷指令包、Git 或客户端。
- bridge URL 固定为 `http://127.0.0.1:8797/api/integrations/sentelligent/bookkeeping`，禁止重定向和任意目标地址。
- 超时、网络错误、4xx/5xx、超大响应、错误 JSON 或不完整响应全部 fail closed；失败记录释放租约后允许安全重试。
- 森特到轻氧的远端幂等键由账号和原始幂等键派生；响应丢失后的重试不会在轻氧重复记账。
- 快捷指令生成的幂等键只基于 OCR 文本、分类和备注，不依赖运行时日期；整条快捷指令在响应丢失后重跑仍使用同一 key。

## 发布与回滚顺序

1. 先发布并验证轻氧桥接版本，保持森特 v0.6.1 不变。
2. 为两套服务配置同一条专用 bridge credential：只写入各自受保护环境文件，不在终端或报告中回显。
3. 轻氧桥接 preflight、迁移和隔离 smoke 全部通过后，再发布森特 v0.6.2、演练 `0018` 并要求 `27/27` preflight。
4. 原子切换森特后先验证 Token、catalog、本地出差报销和 biubiu 合成幂等流程，再允许真实快捷指令验收。
5. 若轻氧失败，先将森特回滚到 v0.6.1，避免继续产生跨系统请求；随后回滚轻氧。`0018` 为只新增表迁移，可随数据库备份整体回滚，不单独删除表。
