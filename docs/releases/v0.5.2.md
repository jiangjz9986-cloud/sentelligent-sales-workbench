# Sentelligent v0.5.2

## Scope

v0.5.2 is a pre-cutover compatibility patch for deploying the persistent Clawbot assistant from the existing v0.4.4 production release. It does not change business APIs, database migrations, assistant tools, or the personal natural-week reimbursement workflow.

## Fix

The v0.4.4 production manifest is schema 3 but predates the `ASSISTANT_CONFIRMATION_SECRET` environment name added by v0.5.0. The strict v0.5.1 validator therefore rejected the old current release before it could produce the required 25/25 pre-cutover report. v0.5.2 recognizes that exact older environment-name set only when the manifest resolves to the canonical `current` release, while keeping all candidate releases on the complete current contract and retaining normal schema-3 file, dependency, migration, archive, and immutable-ownership verification.

## Deployment boundary

Install v0.5.2 into a new root-owned immutable release directory from the GitHub Release archive. The existing release, database, shared Caddy, Qingyang, account-vault, Mihomo, and protected listeners remain untouched until a fresh 25/25 preflight and guarded three-service cutover pass.

## Evidence policy

Record only non-secret commit IDs, tags, archive digests, release/evidence paths, timestamps, check counts, and protected-service fingerprints. Never record credentials, cookies, private keys, model output, database rows, or business attachments.
