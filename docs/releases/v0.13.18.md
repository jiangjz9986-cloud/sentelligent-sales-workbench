## 变更内容

- 增加滨州公共资源交易平台全文检索适配器，按租户和医院名称精确检索，并仅接收公告标题命中医院全称或显式医院别名的结果。
- 为济宁地区平台搜索页启用同样的标题归属校验；青岛继续使用行政区划抓取，并只将明确命中医院名称的公告归属到客户。
- 将客户的医院别名与需求、商机、摘要等业务匹配词分开，防止业务词扩大公告归属范围。
- 修复东营平台医院关键词搜索的结果归属校验；为公告采集 HTTP 客户端增加有解压大小上限的 gzip 支持。
- 对没有经官方来源核验的医院官网公告页不使用第三方聚合站点替代；保留可验证的属地公共资源平台检索来源。

## 验收

- 医院招标采集器单元测试：37 项通过。
- `npm run qa:full`：后端、前端、浏览器多视口、Chrome 集成和 WebKit 验收通过。
- 对济宁 11 个区域入口、东营 18 家客户、滨州 5 个交易平台租户执行只读联网抽测；未触发生产采集任务或真实推送。
- 生产客户数据更新和部署后检查以本次发布 evidence 与客户 API 响应为准。
