# 森特智行 v0.2.4

`v0.2.4` 完成销售决策模型阶段对象的服务端规范化。它延续 `v0.2.3` 的 current-stage 修复，并处理生产模型持续返回非规范 recommended-stage 的情况。

## 修复

- `stage.current` 始终由已存商机事实映射为规范阶段。
- `stage.recommended` 属于九个规范枚举时保留模型建议；否则保守回落到 current，不允许未知模型标签推动阶段。
- 其余 `sales-decision-v1` 字段继续严格校验；非法 JSON、缺失合同字段和越界值仍安全降级。

## 变更边界

- 无数据库迁移。
- 无依赖升级。
- 不修改认证、Caddy、微信会话或共享服务配置。
- 回滚目标为上一已验收 immutable release，数据库不自动回滚。

## 发布门禁

- 完整本地与 GitHub CI 通过。
- GitHub Release 归档 SHA-256 与 manifest commit 一致。
- 生产预检 `19/19`。
- HTTPS 冒烟 `25/25` 且物理清理为 `clean`。
- 浏览器登录与销售决策流程通过，受保护 PID 和 Caddyfile SHA-256 不变。
