## 产品目标

系统服务于一个人持续推进复杂型 B2B 销售。客户信息、商机证据、沟通记录、行动、风险、行程、差旅、待办和周报必须能相互引用，AI 负责提炼、诊断与移动端承接（小小微信助手），最终业务写回由人确认。

## 发布门槛（现行口径）

- 工作树干净、版本四处一致（`VERSION` + 三个 `package.json`）、注释 tag 唯一。
- 当前树和完整历史没有真实凭据（密钥扫描 findings=[]）。
- 门禁链全绿：backend 全量 → `qa:local`（CHROME_PATH 显式传入）→ `qa:integration` → `qa:webkit` → 根 `test:deploy` → `git diff --check`。
- 生产切换按 `docs/releases/` 最近版本证据表的 runbook 执行：串行门 → bundle SHA-256 双端复算 → 服务器 `LC_ALL=C` 打包 → preflight 25/25 → cutover → postflight 25/25 → HTTPS 冒烟 25/25（cleanup=clean）→ 证据回填。
- 只操作 backend、frontend、weixin-agent 三个项目服务；共享 Caddy 与其他服务不随应用重启。
- 上一 release 与数据库备份已记录，应用可独立回滚。
