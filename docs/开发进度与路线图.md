# 开发进度与路线图

更新日期：2026-07-26

## 产品目标

将系统建设为个人使用的 AI 销售作战台，使客户信息不丢、商机状态清晰、下一步行动连续、风险可见、沟通内容可沉淀、周报不再依靠手工汇总。

## 已验证

### 视觉与交互基础

- Apple Design 风格一 PC 与移动端基线
- 响应式主界面和内部滚动区域
- 模块独立搜索
- 列表、只读详情、显式新建/修改/删除的产品规则
- 新建表单默认空白

### 数据与安全

- SQLite 版本迁移和启动完整性检查
- 在线一致性备份、恢复候选验证和损坏拒绝
- 密码哈希、Cookie 会话、注销和会话撤销
- CSRF、Origin 和业务写入输入校验
- 乐观锁、软删除、幂等确认和审计

### 真实业务数据

- 移除前端演示业务回退
- 客户、商机、行动、风险和周报使用后端真实数据
- 商机阶段数量与真实总数守恒
- 方案辅助写入关闭且无模型、数据库或审计副作用

### 快速记录

- 新记录默认选择语音
- 历史分析直接读取持久化结果，不重复调用 AI
- AI 分析可人工修改并保存
- 确认回写使用已保存的修改结果
- 周报真实来源卡片可展开

## 正在开发

### URL 主导页面状态

- 路由解析和生成核心已验证
- 正在整合浏览器前进/后退、模块搜索、详情 ID、滚动恢复和无效 ID 状态

### 语音资产

- 正在建设数据库迁移、私有文件存储、MIME/时长/大小校验和恢复机制

- DeepSeek 不作为语音识别服务；浏览器实时识别只是增强，录音留存和人工补录是基础能力

### 发布候选

- 发布包和生产预检核心已实现
- 正在补齐全测试、备份恢复演练、不可变发布目录和 `/sentelligent/` 路径验收

## 下一阶段

1. 完成 URL 页面整合并通过 PC/移动端浏览器历史测试。
2. 完成语音前后端闭环和 Chrome、iPhone Safari HTTPS 实机验收。
3. 增加快速记录显式修改与删除/作废流程。
4. 建设微信事件、绑定状态和会话草稿持久化，保证幂等和单消费者。
5. 拆分大型 `pages.jsx`，保持行为不变并降低多会话冲突。
6. 完成五个固定视口、真实 Chrome、登录、AI、CRUD、周报和微信验收。
7. 创建生产数据库一致性备份，执行发布、回滚和服务自启动验证。
8. 输出完整迁移手册、私密环境清单、Git bundle 和 SHA-256 校验文件。

## 固定验收视口

| 设备类型 | 视口 |
| --- | --- |
| 大屏 PC | 1440 × 900 |
| 常见笔记本 | 1366 × 768 |
| 小屏 PC/平板横向 | 1024 × 768 |
| iPhone | 390 × 844 |
| Android 窄屏 | 360 × 800 |

所有视口都必须无横向溢出、无文字遮挡、主导航可用、表单可完成、详情和列表可返回。

## 发布门禁

- 当前文件和完整 Git 历史无真实凭据
- 后端、前端、本地 QA、集成 QA 和发布测试全部通过
- 数据库备份可恢复且哈希一致
- 生产环境满足 Node.js 24 和 HTTPS 要求
- 只操作 `sentelligent-*` 服务，不影响同机其他系统
- 新版本可回滚到旧版本
- 现网登录、AI、语音、CRUD、周报和微信流程实际可用
