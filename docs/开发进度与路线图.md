# 开发进度与路线图

更新日期：2026-07-27

## 产品目标

将系统建设为个人使用的 AI 销售作战台，使客户信息不丢、商机状态清晰、下一步行动连续、风险可见、沟通内容可沉淀、周报不再依靠手工汇总。

## 已验证

### 视觉与交互基础

- Apple Design 风格一 PC 与移动端基线
- 响应式主界面和内部滚动区域
- 模块独立搜索
- 列表、只读详情、显式新建/修改/删除的产品规则
- 新建表单默认空白

### 数据与安全

- SQLite 版本迁移和启动完整性检查
- 在线一致性备份、恢复候选验证和损坏拒绝
- 密码哈希、Cookie 会话、注销和会话撤销
- CSRF、Origin 和业务写入输入校验
- 乐观锁、软删除、幂等确认和审计

### 真实业务数据

- 移除前端演示业务回退
- 客户、商机、行动、风险和周报使用后端真实数据
- 商机阶段数量与真实总数守恒
- 方案辅助写入关闭且无模型、数据库或审计副作用

### 快速记录

- 新记录默认选择语音
- 历史分析直接读取持久化结果，不重复调用 AI
- AI 分析可人工修改并保存
- 确认回写使用已保存的修改结果
- 周报真实来源卡片可展开

### 智能拜访行程

- 已完成行程列表、模块内搜索、只读详情、显式新建/修改/删除和最多 8 个停靠点
- 已完成 SQLite 版本化快照、乐观锁、软删除、审计和历史读取零重算
- 已完成确定性排序、预约时间/优先级约束和 DeepSeek 合法排列守门；异常自动回退
- 已接入高德 Web JS Geocoder；后端对浏览器坐标做高德逆地理复核，再调用距离矩阵和驾车路线
- 已验证真实路线：黄岛秀兰禧悦山至济宁第二人民医院约 379.1 km、250 分钟、过路费 146 元，折线 2988 点
- 已验证高德地图 SDK、起点/客户 Marker、折线、导航链接和地图不可用时的路线时间轴降级
- 高德 Web 服务正向地理编码在当前 Key 下返回 `30001`，系统保留服务端正向编码兼容路径，并使用浏览器 Geocoder 回退保证真实新建可用

### 复杂销售决策 Agent V1

- 已完成短核心提示词、行业 playbook、严格 JSON Schema 和确定性回退，不在每次请求中发送完整规则文档
- 已完成事实、推断、未知分离，SPIN/MEDDPICC 阶段门槛、100 分评分封顶、七类决断和合规升级
- 已完成医疗、政企、云、数据中心和信创规则选择；模型输出非法时回退到可审计的确定性诊断
- 已完成受限输入快照和分析快照、只读历史、审计与数据库完整性检查；历史读取不再次调用模型
- 已完成商机详情显式诊断面板，快速记录分析保持原合同，客户/商机/动作/风险不自动写回
- 已验证真实 DeepSeek 结构输出：8 个评分维度通过严格合同，缺预算/决策链/客户承诺仍由本地守门保留，虚构联系人被过滤
- 已通过真实 Chrome 验收：诊断仅一次 `POST 201`、历史仅一次 `GET 200`、业务写回 0 次；五种视口横向溢出均为 0

## 固定验收视口

| 设备类型 | 视口 |
| --- | --- |
| 大屏 PC | 1440 × 900 |
| 常见笔记本 | 1366 × 768 |
| 小屏 PC/平板横向 | 1024 × 768 |
| iPhone | 390 × 844 |
| Android 窄屏 | 360 × 800 |

所有视口都必须无横向溢出、无文字遮挡、主导航可用、表单可完成、详情和列表可返回。
