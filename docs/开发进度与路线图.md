# 开发进度与路线图

更新时间：`2026-07-29T10:46:09+08:00`

## 产品目标

系统服务于一个人持续推进复杂型 B2B 销售。客户信息、商机证据、沟通记录、行动、风险、行程和周报必须能相互引用，AI 负责提炼和诊断，最终业务写回由人确认。

- 生产提交：`f8d43bbfd6172828340a270c5276485192223a65`。
- GitHub Release：[v0.2.1](https://github.com/jiangjz9986-cloud/sentelligent-sales-workbench/releases/tag/v0.2.1)，归档 SHA-256 为 `fbcd705dd28257faec3139f31837bb8562e6f7405b770c402d83c8746789a815`。

- Apple Design 风格一的 PC、iPhone 和 Android 响应式工作台。
- 登录、七天 Cookie 会话、CSRF、Origin、输入校验和登录限流。
- SQLite 迁移、乐观锁、软删除、审计、一致性备份与恢复门禁。
- 客户、商机、行动、风险、知识、周报、看板和总览的真实后端数据。

- 微信绑定入口、worker 服务和状态查询。
