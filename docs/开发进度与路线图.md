# 开发进度与路线图

更新时间：`2026-07-29T03:08:13.542+08:00`

## 产品目标

系统服务于一个人持续推进复杂型 B2B 销售。客户信息、商机证据、沟通记录、行动、风险、行程和周报必须能相互引用，AI 负责提炼和诊断，最终业务写回由人确认。

## 已部署并验证

- Apple Design 风格一的 PC、iPhone 和 Android 响应式工作台。
- 登录、七天 Cookie 会话、CSRF、Origin、输入校验和登录限流。
- SQLite 迁移、乐观锁、软删除、审计、一致性备份与恢复门禁。
- 客户、商机、行动、风险、知识、周报、看板和总览的真实后端数据。
- 快速记录默认语音、DeepSeek 分析、结果持久化、人工修改和确认写回。
- 销售决策 Agent V1 的显式诊断、不可变输入/输出快照和只读历史。
- 高德地址解析、路线、里程、时间、费用、地图和 DeepSeek 受约束顺序优化。
- 微信绑定入口、worker 服务和状态查询。
- 不可变 release 目录、项目独立 Node.js 24、systemd 自启动和共享 Caddy 保护。

生产基线为 `f89e1e7`，部署时间 `2026-07-28T22:30:21+08:00`。验收证据为公开 HTTPS 冒烟 `25/25`、生产预检 `18/18`、数据库 `quick_check=ok`、外键违规 `0`。
