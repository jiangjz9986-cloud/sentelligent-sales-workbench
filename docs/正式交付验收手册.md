# 森特智行 AI 销售作战台正式交付验收手册

更新时间：2026-06-06

## 1. 交付范围

本项目当前交付的是可运行 MVP：React 前端、Node 后端、SQLite 数据库、本地开发脚本、WSL 生产栈脚本、DeepSeek 后端模型接入、审计日志和自动化 QA 验收脚本。

当前业务访问地址：

- 前端业务地址：http://127.0.0.1:5184
- 后端接口地址：http://127.0.0.1:8897

核心业务闭环：

- 战情总览：进入客户、商机、快速记录、行动、风险、知识库和周报。
- 快速记录：支持文本和语音转写入口，默认新增记录为空；历史记录可载入已有分析并允许人工修改。
- 客户画像：先看客户列表，点击查看详情后进入客户维护界面；新增客户直接进入空表单。
- 商机档案：先看商机列表，点击查看详情后进入商机维护界面；新增商机直接进入空表单。
- 下一步行动、风险识别、知识库、商机看板和周报：均应支持列表搜索、详情查看、状态更新或内容生成。
- AI 能力必须只在后端调用，前端不保存、不展示、不构建任何模型密钥。

## 2. 本地启动与停止

从 Windows 项目根目录执行：

```powershell
cd C:\Users\50159\Desktop\森特智行
npm run dev:start
npm run dev:status
```

`npm run dev:status` 应确认：

- frontendStatus 为 200。
- backend 数据库 ready。
- aiAnalysisMode 为 model。
- modelProvider 为 deepseek。
- modelName 为 deepseek-v4-flash，对外交付名称为 DeepSeek-V4-Flash。
- modelReady 为 true。

停止本地服务：

```powershell
npm run dev:stop
```

## 3. 后端模型与密钥边界

模型密钥只允许放在 backend .env。不要写入前端源码、构建产物、截图、文档、周报、提交说明或日志。

后端模型配置边界：

- DeepSeek-V4-Flash 通过后端 OpenAI-compatible chat completions 调用。
- 健康检查只允许暴露模型模式、供应商、模型名和 ready 状态。
- 任何接口响应不得返回 provider key、Authorization header 或原始密钥片段。
- 自动化测试默认使用 mock 或受控环境，避免消耗正式模型额度。

密钥扫描：

```powershell
npm run scan:secrets
```

## 4. 审计日志

后端应记录关键写操作和 AI 触发动作，便于后续追溯：

- 客户新增、修改。
- 商机新增、修改。
- 快速记录分析、确认、同步客户或商机、进入周报。
- 周报草稿生成。
- 方案草稿生成。
- 风险状态更新。
- 知识库新增、修改。

审计接口：

```text
GET /api/audit-logs
```

验收时可访问：

```powershell
Invoke-RestMethod http://127.0.0.1:8897/api/audit-logs
```

审计记录不应包含模型密钥、完整请求头或敏感环境变量。

## 5. 完整自动化验收

每次正式交付、合并或现场演示前，运行：

```powershell
npm run qa:full
```

该命令应覆盖：

- 根目录敏感信息扫描。
- 根目录部署脚本测试。
- 后端 API、数据库、模型降级、安全响应和审计日志测试。
- 前端构建。
- 前端快速记录、周报、API 合同和静态服务测试。
- 浏览器集成 QA，包含桌面、平板、iPhone 和安卓窄屏响应式检查。
- 关键业务点击流，包括快速记录、客户、商机、知识库、周报、方案和风险状态。

如果只检查部署脚本和安全边界，可运行：

```powershell
npm run test:deploy
```

## 6. WSL 生产栈验收

WSL 生产栈用于模拟正式运行方式。执行：

```powershell
npm run wsl:stack:start
npm run wsl:stack:health
npm run wsl:stack:status
npm run wsl:stack:smoke
npm run wsl:stack:stop
```

默认地址：

- WSL 后端：http://127.0.0.1:8897
- WSL 前端：http://127.0.0.1:8088

验收标准：

- 后端 `/api/health` 返回 ok、database ready。
- 前端 `/_health` 返回 ok。
- 前端构建时只写入 API base URL，不写入模型密钥。
- WSL smoke 能完成启动、健康检查和停止。

## 7. 人工验收清单

浏览器使用 100% 缩放打开 http://127.0.0.1:5184，依次确认：

- 外层窗口保留圆角边框，但边距已经收紧，页面不出现横向滚动。
- 顶部品牌区只显示新 logo，不再出现额外“森特智行 / AI 销售作战台”文字。
- 每个模块内部都有独立搜索，不再使用全局搜索框。
- 客户、商机、知识库等列表页先展示列表，点击“查看详情”进入详情页。
- 新增客户、新增商机、新增知识默认进入空表单，不继承上一条记录。
- 页面内容在主界面内滚动，长数据不会把导航和顶部区域拖没。
- 卡片、列表行和按钮不是静态样子，点击后有跳转、展开、状态更新或保存动作。
- 移动端苹果或安卓浏览器打开时，无横向溢出，主要按钮可点击。

## 8. 故障处理

如果前端打不开：

```powershell
npm run dev:status
npm run dev:stop
npm run dev:start
```

如果后端接口异常：

```powershell
Invoke-RestMethod http://127.0.0.1:8897/api/health
npm --prefix backend test
```

如果怀疑密钥泄露：

```powershell
npm run scan:secrets
```

如果 WSL 生产栈异常：

```powershell
npm run wsl:stack:status
npm run wsl:stack:stop
npm run wsl:stack:start
npm run wsl:stack:health
```

## 9. 不进入本轮交付的边界

以下能力不作为当前 MVP 完成标准：

- 多租户权限和角色审批流。
- Word、PDF 或 PPT 自动导出。
- 附件上传与向量检索。
- 正式生产域名、HTTPS、外网部署和运维监控。
- 财务级权限、合同流和回款系统对接。
