## 这次更新了什么

- 公告列表接口增加 `total / limit / offset / hasMore`，避免前端静默截断。
- 搜索、公告类型、相关性和客户筛选交给后端，并支持分页、加载更多和清除筛选。
- 增加高相关、临近截止、今日新增和最新公告时间等指标。
- 区分检测运行中、成功、部分完成、失败和停用状态。
- 展示来源健康、最后成功时间、公告数量、轮巡进度和 PushPlus 配置状态。
- 优化桌面端和移动端信息层级、截止时间、相关性标签及导航定位。
- 详情抽屉支持焦点进入、Tab 循环、Escape 关闭和焦点恢复。

## 用户可见结果

- 筛选结果总数与后端口径一致，不因默认页大小丢失匹配公告。
- 高相关和临近截止机会更容易被识别。
- 来源部分失败会显示为部分完成，不再伪装成全部成功。
- 未配置 PushPlus 时明确显示“仅保存，不推送”。
- 移动端保留截止时间、相关性和主要操作。
