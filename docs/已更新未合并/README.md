# 已更新未合并

这里集中登记“已经开发、已经提交、暂未合并主线”的功能。代码仍保留在各自独立分支中；本目录只保存可审查的范围、证据、边界和后续动作，避免把未验收功能误当成生产能力。

## 状态约定

- **已开发 / 待主控审查**：功能已在独立分支提交，尚未合并。
- **验证部分通过**：自动化证据已列出，但仍有浏览器、真实服务或产品决策门禁。
- **阻塞**：记录具体环境或外部依赖，不以“未完成”替代原因。
- **已合并**：条目应从本目录移到正式发布记录，不再作为未合并功能维护。

## 新增条目模板

新增未合并功能时，建议复制现有条目并至少填写：

1. 功能名称、代码分支、基线提交和最新提交。
2. 已实现范围、明确未包含范围和受保护的共享文件。
3. 自动化测试、浏览器/真实服务证据及其限制。
4. 数据库、生产、凭据和部署影响。
5. 合并前置条件、阻塞项和建议的 cherry-pick 顺序。

所有条目不得写入密码、Token、Cookie、真实附件、客户原文或财务原件。
