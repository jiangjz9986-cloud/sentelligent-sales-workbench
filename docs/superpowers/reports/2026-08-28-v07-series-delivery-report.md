## 3. 已知遗留与决策项清单

1. **存量客户 owner 不一致**（v0.7.2 只读数据体检）：生产存量活跃客户 1 个，owner 非空但 ≠ `WEIXIN_AGENT_OWNER`，对小小不可见（历史现状非该版引入）；归属调整留给用户在 Web 端决定。
2. **owner 为空的存量待办微信端只读保护**（v0.7.5）：迁移 0028 只回填自挂接客户的存量行，owner 为空的行小小侧不可写。
3. **aliases/tags 无 Web 表单**（v0.7.2 设计开放问题 2）：Web API 已接受 aliases/tags，但网页表单未提供，设计建议并入 J 阶段（v0.8.1 视觉统一）补齐。
4. **到点提醒依赖微信绑定私聊与 worker 在线**（v0.7.5）：未绑定无法投递；worker 离线时跳过不标记、恢复后补发，迟到 >24h 标注"过期待办"；单次提醒不重复催办，逾期汇总催办待 v0.7.7 晨报承接。
5. **"修改客户 …"前缀在记账草稿活跃期被记账纠错意图优先消费**（v0.7.2 偏差 5，既有惯例保留）：此场景请改用"把X的…改成…"或"改档：X，…"句式。
6. **结构化数组字段微信端不可改**（v0.7.2 边界）：stakeholders/decisionChain 等在微信端拒绝并提示到网页修改；`contact` 变更在审计 before/after 中被脱敏器剔除（预期行为，changedFields 可证明改动）。
7. **时间解析不支持分钟级相对时间**（代码核实 `spokenTime.js`）："5分钟后/半小时后"不解析，仅支持日期词（明天/后天/下周X/X月X日/N天后/月底等）+ 时刻词（上午十点/下午3点半/14:30 等）；真机验收话术需用时刻表达。
8. **v0.7.5 测试基线口径不一致**（待核实）：v0.7.5 文档记 v0.7.4 基线 1158，v0.7.4 文档与 CHANGELOG 记 1148。

## 5. 系统配置页复核项（记账日志）

页面：系统配置 → **记账日志**（`/settings/bookkeeping-log`，子导航第 5 项）；每 10 秒自动轮询 + 手动"刷新"按钮；删除/拒绝/失败类动作带红点标识；时间为 HH:mm:ss 本地时间，含单据短标识与金额/摘要提取。

应能出现的流水类型（服务端 scope 白名单六前缀，中文标签取自前端 `BOOKKEEPING_ACTION_LABELS`）：

| 分组 | 流水类型（中文标签） |

| 付款凭证收件箱（travel_expense_document_inbox.*） | 收到付款凭证、确认付款凭证、拒绝付款凭证 |
