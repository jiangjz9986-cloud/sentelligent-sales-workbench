# v0.2.3 Model Stage Hotfix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prevent otherwise valid DeepSeek sales-decision responses from falling back on a non-canonical current stage, restore the CentOS post-stop listener gate, then publish and deploy the verified patch release.

**Architecture:** Treat `stage.current` as server-owned evidence derived from the stored opportunity, never as model-owned output. Preserve strict validation for other model fields, and use portable awk field variables so the controlled cutover fails closed when project listeners remain open.

**Tech Stack:** Node.js 24, built-in `node:test`, GitHub Actions/Releases, systemd, SQLite.
