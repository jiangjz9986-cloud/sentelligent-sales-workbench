# v0.2.2 Production Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Release `v0.2.2` with reliable quick-record voice defaults, compact mobile navigation, explicit customer edit/delete workflows, production-safe HTTPS smoke cleanup, immutable release verification, and auditable deployment evidence.

**Architecture:** Keep React business views inside the existing workbench shell and make navigation state changes pass through one function. Treat production verification as a fail-closed chain: immutable package hashes, database identity binding, isolated write smoke, exact or UUID-marker-recovered cleanup, service-boundary snapshots, and post-deploy browser evidence. GitHub `main`, the annotated tag, Release archive, and production `current` target must resolve to the same commit.

**Tech Stack:** React 19, Vite 6, Node.js 24, Node test runner, Chrome CDP, Playwright WebKit, SQLite, GitHub Actions, systemd, Caddy.
