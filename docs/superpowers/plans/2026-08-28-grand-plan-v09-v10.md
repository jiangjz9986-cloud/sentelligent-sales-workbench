## 1. 需求分析：从"你的目的"到产品承诺

用户画像：医疗行业销售，经常出差，微信重度；即将扩展第二使用者（D1 待确认是谁）。"完美的智能 AI 销售助手"拆解为六项可验收的产品承诺：

| # | 承诺 | 现状 | 差距主证据 |
| --- | --- | --- | --- |
| P1 采集无感 | 说一句话/拍一张照=完成记录 | 微信主干已达成（记账/拜访/待办全链） | Web 语音依赖浏览器 Web Speech，国内 Chrome 不可用（审计B §2） |
| P2 洞察主动 | 系统先开口（晨报/推送/提醒） | 雏形已具（晨报+招标推送+到点提醒） | 情报不转化为行动：招标命中→商机断链、拜访→温度断链（审计A §5） |

| P6 永不失忆 | 数据与进度永不丢 | 每日备份+不可变发布已上线 | 全栈零告警（挂了没人知道）；无异地副本（审计A §6 A2/D2） |

## 2. 系统现状全景（三审计合成）

- **架构面（审计A）**：单机 CentOS 7 三项目共存；54 表 / 约 115 端点 / assistant 六层编排链 / 三调度器 / outbox 唯一出站通道。十项架构资产明确"改造勿破坏"（不可变发布、租约幂等、R0–R3 策略默认拒绝、owner 过滤单文件收敛等）。债务登记簿 14 项，高危三件：root 孤儿进程（S1）、Web 零隔离（S2）、零告警（A2）。
- **体验面（审计B）**：逐页评分 A-（行程/差旅）到 C-（历史方案）；最大结构性差距=**小小对话能力只存在于微信端**；"假展开"七基元是负资产；Top15 差距已按价值×成本四象限排布。
- **功能面（审计C）**：40 项实测 ✅35 / ⚠️4 / ❌1。唯一 ❌ 是"招标摘要"微信意图未注册；⚠️ 四项（修改客户被记账前缀拦截 / 审计配方 owner 口径 / 行程无 AMAP mock / 招标页测试游离门禁）全部有修复建议；另有 8 条测试盲区清单。
- **总评**：地基坚固（发布/数据完整性/确认安全模型是同类系统少见的水准），上层的"多人、主动、移动"是明确的下一代主战场。

## 3. 大目标定义：v1.0 验收标准（全部可实测）

1. **多账号**：≥2 个真实账号（Web 登录 + 各自微信绑定），跨账号隔离矩阵测试全绿，零越权。
2. **双端对话**：微信与 Web 都能与小小对话（同一 assistant runtime、同一确认安全模型）。
3. **出差场景**：手机断网可查今日行程/待办/客户电话（离线只读壳）；语音记录不依赖浏览器内置识别。
4. **情报转行动**：招标命中可一键转商机+待办；拜访确认自动建议客户温度；发票逾期自动升级提醒。
5. **自我守护**：备份/调度器/worker 任一失败 5 分钟内推送小小告警；异地备份副本每日同步。
6. **质量收口**：审计矩阵 40 项全 ✅，8 条盲区各有守护测试或书面豁免；全部十四份主文档与实现同步。

## 5. 多线并行编排方案

**核心纪律（继承 v0.7/v0.8 已验证模式）**：实施与部署**单 worktree 串行**（同一时刻只有一个实施工人），并行面全部是**只读代码+新文件**（设计/研究/测试/文档/验收）。

四条泳道：

| 泳道 | 职责 | 并行性 |
| --- | --- | --- |
| A 主线实施 | 当前版本的编码+门禁+四关部署（主会话或单实施工人，部署主会话把关） | 串行，一次一版 |
| B 预研设计 | 提前一版产出下一版设计文档（如 A 做 v0.9.1 时，B 出 v0.9.2 的隔离矩阵测试清单与端点改造清单） | 与 A 并行 |
| C 测试与验收 | 盲区守护测试补全（合成栈）、生产验收走查、审计矩阵复测 | 与 A 并行（合成栈隔离/生产只读） |
| D 运维监察 | 告警首发验证、备份新鲜度、outbox 陈账核销、服务器清理执行 | 低频并行（只读+已批准的清理动作） |

**标准节拍**（每版）：B 预研落档 → A 实施+门禁（backend 全量/前端 qa:local/集成/秘密扫描/deploy 测试）→ 四关部署 → C 生产验收 → 证据回填 release 文档 → 下一版。
**异常接管协议**：工人 503 中断→主会话从断点续做（v0.7.3/v0.8.1 先例）；网络/额度中断→计划文档+todo 持久化，任何新会话读 `docs/superpowers/plans/` 即可无损续跑。

## 6. 决策点（2026-08-28 用户已全部拍板）

## 7. 风险与保障

1. **迁移风险（v0.9.0/v0.9.2）**：/dev/shm 彩排+SHA 对账+VACUUM INTO 手动备份+幂等迁移；回滚只回代码不回数据。
2. **越权风险（v0.9.2/v0.9.3）**：隔离矩阵与 scope 矩阵**测试先写**（红→绿）；跨账号访问返回 404 防枚举；投递 scope mismatch 一律终态。
3. **微信投递风险**：坚持单机器人多绑定，不上多 worker；绑定码一次性+TTL。
4. **体验重构风险（v0.10.x）**：先铺路（v0.10.1）再大改；每版视觉节奏截图×6 视口对照。
5. **进度与记忆风险**：方案/设计/审计全部落盘 git；每版 release 文档即断点存档；额度中断任意新会话可续。
6. **架构资产保护**：审计A §8 十项资产列为改造红线，动到即须在 release 文档专节说明。
