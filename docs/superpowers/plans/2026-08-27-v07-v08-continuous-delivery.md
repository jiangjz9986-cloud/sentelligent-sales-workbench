## 每阶段固定完成定义（DoD）

1. 后端全量 + 前端 qa:local + Chrome 集成 + WebKit + 密钥扫描 + 根 test:deploy 全绿；`git diff --check` 干净。
2. CHANGELOG 条目 + `docs/releases/vX.Y.Z.md` + 版本号统一 + 注释标签（本地 exact-commit，不推 GitHub）。
3. 生产：preflight 25/25 → cutover passed → postflight 25/25 → HTTPS 冒烟 25/25 cleanup=clean（临时凭据字节级恢复），回滚点记录。
4. 浏览器验收：本地隔离栈（合成数据）功能走查 + 桌面/移动截图；生产公网健康 + 关键页只读确认。
5. Canvas 看板与本文件状态行更新；聊天发一条里程碑。

## 边界（全程不变）

- 不写真实业务数据（验收只用本地合成栈）；不操作微信 UI；真机验收由用户执行。
- 生产发布严格串行；共享 Caddy/其他服务不动；密钥不落盘不入日志。
- 门禁失败必须修复重跑，不得跳过；生产异常立即回滚上一版。
- 模型路由不变（文本 deepseek-v4-flash；图片/PDF deepseek-v4-flash-vision-exp）。
